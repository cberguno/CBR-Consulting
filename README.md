# CBR Consulting

**AI Consulting business located in Dallas, TX**

A professional static website for CBR Consulting — an AI strategy and implementation firm headquartered in Dallas, Texas.

## Structure

| File | Description |
|------|-------------|
| `index.html` | Main website — Hero, Stats, Services, About, Process, Contact |
| `styles.css` | All styling (responsive, mobile-first) |
| `script.js` | Mobile nav, scroll-reveal animations, counter animation, contact form validation |

## Running Locally

Open `index.html` directly in a browser, or serve with any static file server:

```bash
npx serve .
# or
python3 -m http.server 8080
```

## Sections

- **Hero** — Tagline, value proposition, and primary CTAs
- **Stats** — Animated counters (projects, satisfaction, efficiency, industries)
- **Services** — AI Strategy, Generative AI, ML Engineering, Automation, Governance, Training
- **About** — Company background, values, Dallas HQ
- **Process** — 5-step engagement methodology
- **Contact** — Info + validated contact form
